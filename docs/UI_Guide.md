# 画面と言語

Web画面の右上から「日本語 / English」を選択できます。初期値は日本語で、選択をブラウザに保存します。言語変更ではカメラ、姿勢推定、接続、入力中のフォーム、開いている詳細画面を作り直しません。参加者名とイベント名は翻訳しません。組み込みポーズ名、カメラ案内、判定理由、サーバーの既知のエラーは翻訳します。

## 観察者

プレイ中は画面の残りの領域をカメラへ割り当て、ラウンド・経過時間・お手本・一致度・判定案内を常時表示します。映像と骨格は同じ比率で表示し、UI側で映像を切り取ったり引き伸ばしたりしません。カメラには表示領域に近い比率を要求しますが、実際の比率は端末が対応する形式によって異なります。回転時も取得比率を調整します。取得サイズは長辺640pxを目安とし、画面拡大によって推論負荷が過度に増えないようにします。

右上のお手本をタップすると拡大できます。「詳細」からチーム全員の状況、クリア人数、判定方式・保持時間・制限時間、遊び方、色の説明を確認できます。カメラの再試行も詳細から可能です。カメラが準備できるまでは起動ボタンと案内が映像領域に表示されます。

## その他の画面

- ポーズ役：大きな3D表示と準備ボタンを中心にし、チーム状況は「詳細」へまとめます。回転操作と顔の表示は維持します。
- 待機画面：開始待ちの案内を表示し、メンバー一覧を展開して確認できます。
- 結果画面：直近の結果とチームベストを表示します。「過去のラウンド・参加者別結果」から全履歴と各参加者の結果を確認できます。
- 管理画面：進行操作・QR・参加者の状態を優先し、判定設定と履歴は折りたたみます。入力途中でも言語を切り替えられます。
- 会場LANの証明書設定ページ：上部に日本語・英語のリンクがあります。

Webの翻訳は `frontend/src/locales/en.json` に集約しています。日本語の表示文字列をキーとして使います。同じ英語を複数の日本語へ逆変換する曖昧さを避けるため、異なるキーには異なる英訳を使います。言語切り替え時は既存のテキストとラベルを更新し、ユーザー入力の要素は対象外にします。数値、イベント名、参加者名などはテンプレートの値として扱います。

共通Web UIは `main` と `feat/windows-desktop-app` の両ブランチに反映します。Windows固有の起動画面とビルド設定はWindowsブランチだけに含まれます。
