アプリを終了してから、**Win + R** を押し、次を入力して実行してください。

```text
%LOCALAPPDATA%\Programs\PoseParallax\unins000.exe
```

通常、アンインストーラーは次の場所にあります。

```text
C:\Users\<ユーザー名>\AppData\Local\Programs\PoseParallax\unins000.exe
```

Windowsの「設定 → アプリ → インストールされているアプリ → Pose Parallax」からも削除できます。

**保存データは残ります。** データも完全に削除したい場合は、アンインストール後に次のフォルダーを削除してください。

```text
%LOCALAPPDATA%\PoseParallax
```

※ ZIP内の `PoseParallax.exe` を直接使っていた場合は、展開したフォルダーを削除するだけです。
