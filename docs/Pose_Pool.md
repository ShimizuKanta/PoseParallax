# 全身ポーズの共通プール

24種類を1つのプールへ混ぜ、ラウンドごとにランダムに選びます。難易度の段階・別プール・レベル選択はありません。元の4種類も全身の姿勢を調整して残しています。単なる左右反転の水増しは行いません。

[全24種類を正面・斜めから見る](pose_catalog.svg)

片足を浮かせる形は3種類（全体の12.5%）です。それ以外は両足を床につけます。ジャンプ、深いスクワット、床への膝・手・胴体の接触、極端な開脚や大きな反り返りは含めません。

## 関節と視点の品質

腕・脚の各節の長さは全ポーズで固定です。手首・足首の位置と肘・膝の曲がる方向を定義し、2節の逆運動学で中間関節を求めます。届かない手足の位置は伸縮で補わず、定義エラーとして拒否します。地面につける脚の膝は前に曲げ、浅い曲げに限定しています。

設定した関節間隔、左右間隔、投影された手足の長さを満たさない視点は従来どおり破棄します。管理者の条件によって選ばれたポーズの視点が作れない場合は、同じプールの別候補をランダム順で試します。条件を緩める処理はありません。全候補が不適合なら設定エラーを返し、ラウンド・ポーズ役の担当回数を変更しません。

自動テストで、長さ、足の接地、浅い膝曲げ、足の幅、胴体の動き、類似ポーズの排除、全ポーズの49人分の既定視点、設定した関節間隔を確認します。正面・斜めから描画した一覧も確認します。実際の参加者による動作とスマートフォンでの姿勢認識は会場検証の対象です。

保存済みラウンドはそのときの関節座標を保持します。新しいポーズ集合は次に準備するラウンドから使います。ポーズ名は日本語・英語に対応します。
